# Kolobot 🤖📁

**Kolobot** — це асинхронний Telegram-бот (на базі `aiogram` v3), який слугує розумним персональним архівом документів та системою складського обліку. Бот розпізнає текст і табличні дані з фотографій та PDF-документів за допомогою Google Gemini API, структурує дані, зберігає їх у векторну базу (ChromaDB) та складську базу (SQLite), і дозволяє шукати інформацію за допомогою семантичного пошуку (RAG) та керувати нею через веб-інтерфейс.

## 🚀 Основні можливості

- **OCR та структурування документів**: Розпізнавання тексту та вилучення структурованих полів (номер документа, дата, номенклатура, кількість, ціни, суми, контрагенти) за допомогою моделі Google Gemini (`gemini-2.5-flash`).
- **Розумний архів (RAG)**: Пошук по документах за допомогою семантичного векторного пошуку (`text-embedding-004` + ChromaDB). Можливість ставити боту питання природною мовою та отримувати відповіді з посиланнями на оригінальні файли.
- **Складський облік**: Автоматичне ведення товарного обліку (прихід, розхід, залишки, історія транзакцій) у SQLite з можливістю імпорту та експорту в Excel (`.xlsx`).
- **Пул API ключів**: Вбудований менеджер пулу ключів `KeyPool` для Google Gemini з ротацією, rate-limiting (обмеження запитів RPM/RPD) та автоматичним кулдауном.
- **Веб-інтерфейс**: Вбудований локальний веб-сервер для перегляду та керування складом і документами.

## 🛠 Вимоги до системи

- **Python**: 3.9+ (рекомендовано 3.12 або 3.13)
- **Telegram Bot Token**: Отримується у [@BotFather](https://t.me/BotFather)
- **Google Gemini API Keys**: Отримуються у [Google AI Studio](https://aistudio.google.com/)

## 📦 Встановлення

1. **Клонуйте репозиторій:**
   ```bash
   git clone <url-вашого-репозиторію>
   cd kolobot
   ```

2. **Створіть та активуйте віртуальне середовище:**
   ```bash
   python -m venv .venv
   
   # Windows:
   .venv\Scripts\activate
   
   # Linux/macOS:
   source .venv/bin/activate
   ```

3. **Встановіть залежності:**
   ```bash
   pip install -r requirements.txt
   ```

## ⚙️ Налаштування

1. Скопіюйте файл-приклад конфігурації `.env.example` у файл `.env`:
   ```bash
   cp .env.example .env
   # для Windows: copy .env.example .env
   ```

2. Відкрийте `.env` та заповніть параметри:
   - `BOT_TOKEN`: Ваш токен Telegram-бота.
   - `OWNER_USER_ID`: Ваш числовий Telegram ID (доступ суворо обмежений для власника).
   - `GEMINI_KEYS_GENERATE`: Один або декілька API-ключів Gemini для OCR та генерації відповідей (через кому).
   - `GEMINI_KEYS_EMBED`: Один або декілька API-ключів Gemini для ембеддінгів.
   - `CHROMA_PATH` та `DOWNLOADS_PATH`: Шляхи до бази векторів та збережених файлів (наприклад, `./data/chroma` та `./downloads`).

## ▶️ Запуск

Запустіть бота та веб-інтерфейс однією командою:
```bash
python -m kolobot
```

### 🌐 Веб-інтерфейс
Якщо у файлі `.env` встановлено `WEB_ENABLED=true` (за замовчуванням), веб-сервер автоматично запуститься за адресою:
👉 **http://127.0.0.1:8000**

У веб-інтерфейсі доступні вкладки:
- **Склад**: Перегляд залишків, пошук товарів, розгортання історії руху по кожній позиції, експорт та імпорт Excel.
- **Документи**: Перегляд завантажених документів, відкриття оригіналів, видалення з автоматичним перерахунком залишків.

## 💡 Як користуватися ботом

1. Запустіть бота командою `/start` у Telegram.
2. Надішліть боту **фотографію** або **PDF-документ** (накладна, чек, акт, вимога тощо).
3. Бот розпізнає документ через Google Gemini API, надішле структуровану картку на підтвердження.
4. Натисніть **Зберегти**, щоб документ зберігся в архіві та оновив залишки на складі.
5. Для пошуку просто надішліть питання боту текстовим повідомленням (наприклад: *"Скільки ми отримали кабелю минулого тижня?"*).
