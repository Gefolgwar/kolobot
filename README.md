# Kolobot 🤖📁

**Kolobot** — це асинхронний Telegram-бот (на базі `aiogram` v3), який слугує розумним персональним архівом документів. Бот розпізнає текст з фотографій та PDF-документів за допомогою потужної локальної OCR-моделі, структурує дані, зберігає їх у векторну базу (ChromaDB) і дозволяє шукати інформацію за допомогою природної мови (RAG).

## 🚀 Основні можливості

- **Локальний OCR для зображень та PDF**: Використовує модель `baidu/Unlimited-OCR` для точного розпізнавання тексту (з підтримкою таблиць, чеків, накладних тощо). Модель працює повністю локально на вашій відеокарті.
- **Альтернативні OCR-бекенди**: Підтримка `Qwen3-VL-2B` (локальна VLM з OCR + структуруванням) та `Gemini API` (хмарна, найшвидша та найякісніша).
- **Розумний архів (RAG)**: Пошук по документах за допомогою семантичного векторного пошуку. Можливість ставити боту питання по завантажених документах.
- **Пул API ключів**: Вбудований менеджер пулу ключів для Google Gemini (або NVIDIA NIM) з ротацією, rate-limiting (обмеження запитів RPM/RPD) та автоматичним кулдауном.
- **Веб-інтерфейс**: Вбудований локальний веб-сервер для керування архівом.

## 🛠 Вимоги до системи

- **ОС**: Linux / Windows
- **Python**: 3.9+ (рекомендовано 3.12, протестовано з `torch 2.10` та CUDA)
- **GPU**: Відеокарта NVIDIA з підтримкою CUDA (необхідно для швидкої роботи локальної моделі OCR)
- **Telegram Bot Token**: Можна отримати у [@BotFather](https://t.me/BotFather)
- **API ключі**: Google Gemini (Google AI Studio) або NVIDIA NIM (для ембеддінгів та генерації RAG-відповідей)

## 📦 Встановлення

1. **Клонуйте репозиторій:**
   ```bash
   git clone <url-вашого-репозиторію>
   cd kolobot
   ```

2. **Створіть та активуйте віртуальне середовище:**
   Використовуючи `uv` (якщо встановлено) або стандартний `venv`:
   ```bash
   python -m venv .venv
   
   # Windows:
   .venv\Scripts\activate
   
   # Linux/macOS:
   source .venv/bin/activate
   ```

3. **Встановіть залежності:**
   ```bash
   pip install -r requirements.txt
   ```
   *(Зверніть увагу: при першому запуску OCR-модель розміром близько кількох гігабайт буде автоматично завантажена з HuggingFace).*

## ⚙️ Налаштування

1. Скопіюйте файл-приклад конфігурації `.env.example` у файл `.env`:
   ```bash
   cp .env.example .env
   # для Windows можна використати: copy .env.example .env
   ```

2. Відкрийте `.env` та заповніть необхідні параметри:

   - `BOT_TOKEN`: Ваш токен від Telegram-бота.
   - `OWNER_USER_ID`: Ваш Telegram ID (бот відповідатиме лише вам).
   - `GEMINI_KEYS_GENERATE`: Список API-ключів Gemini для RAG через кому.
   - `GEMINI_KEYS_EMBED`: Список API-ключів для генерації векторів.
   - `CHROMA_PATH` та `DOWNLOADS_PATH`: Шляхи до папок бази даних та завантажених файлів (створяться автоматично, наприклад, `./data/chroma` та `./downloads`).

   *Примітка: для використання NVIDIA NIM змініть `AI_PROVIDER=nvidia` та вкажіть `NVIDIA_API_KEY`.*

## ▶️ Запуск

Для запуску бота та веб-інтерфейсу виконайте команду з кореневої папки проекту:
```bash
python -m kolobot
```

### 🔤 Вибір OCR-бекенду

Бот підтримує три режими розпізнавання тексту:

| Прапор | Бекенд | Опис |
|--------|--------|------|
| *(без прапора)* | `Unlimited-OCR` | Локальна модель Baidu, потребує GPU з CUDA. Дефолт. |
| `--qwen3-vl` | `Qwen3-VL-2B` | Локальна VLM (Vision-Language Model), працює на CPU (FP16, ~4 ГБ RAM). Розпізнає текст і одразу структурує дані (JSON). |
| `--gmodel` | `Gemini API` | Хмарна модель Google Gemini. Найшвидша та найякісніша, потребує API-ключі. |

Приклади запуску:
```bash
# Дефолтний режим (Unlimited-OCR, GPU)
python -m kolobot

# Qwen3-VL-2B (локальна, CPU)
python -m kolobot --qwen3-vl

# Gemini API (хмарна)
python -m kolobot --gmodel
```

> **💡 Порада:** Для найкращої якості розпізнавання надсилайте зображення в Telegram як **файл** (📎), а не як фото — це зберігає оригінальну роздільну здатність.

### 🌐 Веб-інтерфейс
Якщо у файлі `.env` встановлено `WEB_ENABLED=true` (за замовчуванням), веб-сервер запуститься **автоматично** разом із ботом. 
Ви можете отримати до нього доступ через браузер за адресою:
👉 **http://127.0.0.1:8000**

У веб-інтерфейсі ви можете переглядати ваші збережені документи, шукати їх та видаляти за потреби.

## 💡 Як користуватися

1. Запустіть бота командою `/start` у Telegram.
2. Відправте боту **фотографію документа** (чек, накладна, договір) або **PDF-файл**.
3. Бот розпізнає документ локально за допомогою `Unlimited-OCR`, структурує суми, товари і дати, та надішле вам картку документа для підтвердження.
4. Натисніть **Зберегти**, щоб документ потрапив до бази.
5. Для пошуку просто поставте боту питання. Наприклад: *"Скільки я витратив на будівельні матеріали минулого місяця?"*. Бот застосує RAG, знайде відповідні документи і дасть точну відповідь.

## 🏗 Архітектура проекту

- `kolobot/main.py` — Точка входу, реєстрація обробників (handlers) та ініціалізація `aiogram`.
- `kolobot/local_ocr.py` — Сервіси локального OCR: `UnlimitedOCRService` (Baidu) та `Qwen3VLService` (Qwen3-VL-2B, CPU FP16).
- `kolobot/gemini_gateway.py` — Адаптер для роботи з LLM-провайдерами (Google/NVIDIA) для генерації відповідей (RAG) та ембеддінгів.
- `kolobot/vector_store.py` — Векторна база даних на базі ChromaDB.
- `kolobot/rag_service.py` — Логіка Retrieval-Augmented Generation (пошук + відповідь).
- `kolobot/handlers/` — Модулі з обробниками команд Telegram (медіа, команди, тощо).
